# CineVerse-AI-Multi-Language-Movie-Recommender-
Developed a multi-language movie recommendation system that suggests movies in English, Hindi, and Telugu using both content-based and collaborative filtering techniques. The system is enhanced with an AI-powered chatbot and a quiz module that predicts genres based on user interaction and User as option view the trailer at there only

Built an AI-powered movie recommendation system with support for English, Hindi, and Telugu using hybrid techniques.
•	Integrated Gemini LLM to dynamically generate quiz questions and recommendations.
•	Enabled trailer previews, AI chatbot conversations, and cast-based search using TMDb & YouTube APIs.
•	Containerized the application by creating a Docker image for seamless deployment.
•	Tech Stack: Flask, Gemini API, Scikit-learn, TMDb API, YouTube Search
